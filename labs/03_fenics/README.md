# Нагрев пластины

Программа `poisson.py` считает температуру в прямоугольной пластине с двумя нагревателями внутри. Слева температура равна `0`, справа — `1`, а через верхнюю и нижнюю границы тепло не уходит.

Для запуска из этой папки нужно выполнить:

```bash
PYTHONNOUSERSITE=1 python3 poisson.py
```

После расчёта программа показывает график и сохраняет его в файл `poisson_temperature.png`.
